# 2026-04-01 对话记录

## 本次对话主题

项目转型：ChipWhisper → GraphMind

---

## 对话内容

### 1. 转型原因

用户认为原方向（半导体供应链 Graph-RAG 风险推理系统）**数据获取难度过大**，不可行。

主要问题：
- 半导体供应链数据多为非公开的商业数据
- 公司间的真实供应关系难以系统性获取
- 地缘政治事件的结构化标注需要大量人工
- 作为课程项目，数据采集成本过高

---

### 2. 新方向确定

**GraphMind（图智）**：基于知识图谱的个性化学习路径推荐系统

核心思路：
- 将课程体系构建为知识图谱（Neo4j）
- 追踪学生学习状态
- 根据学习阶段动态推荐邻近知识点
- 可视化知识图谱 + LLM 辅助讲解

选择理由：
- **数据可控**：课程大纲、知识点结构可从教学材料提取或自建
- **技术栈复用**：仍然使用 Neo4j + LangChain（Graph-RAG 核心不变）
- **商业化清晰**：面向高校/培训机构/学生的 SaaS 产品
- **可展示性强**：可视化图谱效果直观，适合课程项目演示

---

### 3. 关键设计决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 应用场景 | 计算机科学专业（首期） | 中等复杂度，便于商业化扩展 |
| 技术栈 | 保留 Neo4j + LangChain | 与原方案一脉相承，减少学习成本 |
| 项目名称 | GraphMind（图智） | 强调知识图谱驱动的智能推荐 |
| 核心交互 | 可视化知识图谱 + 动态推荐 | 学生可在图谱上直观看到学习路径和推荐 |

---

### 4. 项目架构规划

- **图数据库**：Neo4j（课程/章节/知识点/概念 四级节点）
- **后端**：Python + FastAPI
- **前端**：React + D3.js（知识图谱可视化）
- **LLM**：LangChain 编排（讲解、关联分析、答疑）
- **用户数据**：SQLite/PostgreSQL（学习记录、用户信息）

---

### 5. 推荐策略设计

1. **前置就绪推荐**：前置依赖全部掌握的知识点
2. **邻近扩展推荐**：已掌握节点的关联邻居
3. **薄弱补强推荐**：掌握程度低的前置节点
4. **路径规划**：给定目标知识点的最短学习路径
